# 月月分红红利ETF组合 · 口径与校验

## 一、这套测算在回答什么问题

不是"哪只红利ETF涨得好"，而是"**100 万放进去，每个月能收到多少现金，三年后还剩多少**"。

这两件事的区别在于：分红是**每份多少钱**，收益是**净值变化 + 分红**。市面上很多测算把两者混在一起，用"市值 × 股息率"当分红，熊市里会算出根本拿不到的现金流。

---

## 二、公式与推导

### 1. 可持续派息率

```
可持续派息率 = 指数税后股息率 − 综合费率
综合费率     = 管理费率 + 托管费率
```

推导：成分股每股派息 → 进入基金资产 → 先扣管理费、托管费 → 剩余部分才能分配给持有人。所以长期能分出来的上限，是指数股息率减掉费率。

**不减费率会虚增 0.2–0.6pp。** 组合加权费率 0.52%，一年就是 5,200 元的差距。

### 2. 为什么按"每份多少钱"算，不按"市值百分比"算

```
月分红 = 持有份数 × 每份年分红 / 12
每份年分红 = 现价 × 可持续派息率
```

你买进去拿到的是**固定份数**（除权除外），每份分红由成分股每股派息决定，与股价无关。

反例：股价腰斩，股息率从 4% 变 8%。按"市值 × 股息率"算，分红金额几乎不变；按"份数 × 每份分红"算，分红也没变。**但真实情况是分红也没变**——变的只是分母。所以两种算法在"分红金额"上其实一致，真正的错误在于用"市值×股息率"去算**未来**分红：它假设分红会随着股息率上升而增加，这是错的。

### 3. 派息兑现率（本 Skill 的核心创新）

```
派息兑现率 = (近12个月单位分红 / 现价) ÷ 可持续派息率
```

指数股息率 5.4%，基金近一年实际只派了 1.4%——差额留在净值里。对你来说那不叫分红，叫账面浮盈。这类产品做"月月分红组合"是错配的。

实测（2026-11-02）：

| 标的 | 可持续派息率 | 近12月实际派息 | 兑现率 | 处置 |
|---|---|---|---|---|
| 520550 恒生港股通红利低波动 | 4.60% | 4.55% | 99% | 入选 |
| 510720 上国红利 | 4.20% | 3.55% | 85% | 入选 |
| 561580 中证央企红利 | 3.70% | 6.18% | 167% | 入选（含资本利得） |

> 兑现率 > 100% 不是好事，说明当年分配里含往期留存或已实现资本利得，不可持续。模型用 min 封顶，不计入"理论口径"。

### 4. 三年收益

```
第 t 年分红   = 投入 × 可持续派息率 × (1 + 分红增速)^(t−1)
第 t 年末市值 = 投入 × (1 + 价格年化)^t
三年总收益    = (期末市值 − 投入 + 累计分红) / 投入
年化          = (1 + 三年总收益)^(1/3) − 1
```

分红按**期初投入**为基数、按增速复利增长，不随市值波动——因为份数不变，每份分红只跟成分股派息有关。

### 5. 权重

默认等权 20%。之所以不按股息率加权：5 只的可持续派息率在 3.62%–4.60% 之间，加权与等权的权重差不到 2pp，没必要把模型搞复杂。


## 五、常见错法速查

| 错法 | 后果 |
|---|---|
| 用"市值 × 股息率"算未来分红 | 熊市里把分红算多，因为股息率是被动抬高的 |
| 不减综合费率 | 虚增 0.2–0.6pp，一年差几千块 |
| 港股不扣 20% 红利税 | 高估约 1pp，排名会把港股系统性抬高 |
| 先去重再筛规模 | 迷你 ETF 当代表，整条指数消失 |
| 用名字查港股指数 | 返回成分股列表，不是指数数据 |
| 拿季度/年度分红的红利 ETF 凑数 | 组合做不到"月月分红"，名不副实 |
| 把"自由现金流"ETF 当红利 | 分红来源不同，不是一回事 |
| 报告里 5 只的业绩取错标的 | 情景锚点失真（先选后取，别先取后选） |
